# Decision Intelligence Project

This project performs data analysis on superstore datasets to identify weaknesses, run machine learning models for profit prediction, and provide recommendations.

## Structure
- `data/`: Contains the CSV datasets
- `src/`: Source code for analysis (main.py)
- `outputs/`: Generated plots and outputs
- `dashboard/`: Streamlit dashboard app

## Installation
1. Install dependencies: `pip install -r requirements.txt`

## Usage
1. Run analysis: `python src/main.py`
2. Run dashboard: `streamlit run dashboard/app.py`

## Phases
- Phase 2-5: Load and clean data
- Phase 6: Strategy definition
- Phase 7: ML modeling
- Phase 8-11: Best model selection, simulation, recommendations, comparison
