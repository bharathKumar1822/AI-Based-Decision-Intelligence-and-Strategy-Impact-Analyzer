## ✨ Features

- 📊 **Overview** — KPI cards with filters (region, category, segment)
- 🧠 **AI Decision Engine** — Ranked strategies with ROI, risk & time-to-impact
- 🔍 **EDA Charts** — Visual insights (profit by category, sales by region, trends)
- ⚠️ **Weakness Detection** — Root-cause analysis for critical business issues
- 🔮 **ML Predictions** — Multi-model comparison (Linear, Ridge, Random Forest, Gradient Boost)
- 🔬 **Model Explainability** — Feature importance & SHAP-style profit driver analysis
- ⚙️ **Strategy Simulation** — What-if analysis with dynamic growth scenarios
- 🚨 **Risk & Anomaly Detection** — Outlier detection & discount risk analysis
- 💡 **Recommendations** — AI-generated step-by-step action plans with do/don't guidance
- ⚖️ **Company Comparison** — Multi-dataset side-by-side analysis
- 🏁 **Conclusion & Report** — AI-generated project summary with PDF export
- 💬 **AI Chat Assistant** — Voice + text Q&A about your data

## 🏗️ Stack

- **Frontend**: Vanilla HTML, CSS, JavaScript (hosted on Vercel)
- **Backend**: Python Flask + Gunicorn (hosted on Render)
- **ML**: scikit-learn, pandas, numpy, matplotlib, seaborn

## 📁 Project Structure

```
├── frontend/          # Static frontend (HTML, CSS, JS)
├── backend/           # Flask API (app.py)
├── data/              # CSV datasets
├── render.yaml        # Render deployment config
├── Procfile           # Gunicorn startup command
└── requirements.txt   # Python dependencies
```
